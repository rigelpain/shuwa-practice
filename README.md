# 手話れんしゅう帳

手話を登録して、自分専用の「手話→字幕」翻訳ツールとして育てられるブラウザアプリです。
手話者が登録した単語帳は、そのまま練習者の教材になります。
ブラウザの中だけで動き、映像や記録はどこにも送信しません。

- **読み取りモード**：カメラの前で手話をすると、登録した単語から一番近いものをその場で字幕に出します。手話の動画ファイルにも、時刻つきの字幕を付けられます
- **記録モード**：単語ごとに見本を登録します。練習者はお手本と比べて練習し、点数とずれた場面を確かめられます
- **話して練習**：話した言葉を字幕にし、単語帳にある言葉の見本を手話モーションとして順に再生します。見ながら一緒に手話できます

公開版：https://rigelpain.github.io/shuwa-practice/

- MediaPipe で手（両手21点ずつ）・上半身・表情・頭の向き（首振り・うなずき・かしげ）を読み取ります
- 片手がもう一方の手に隠れても、体のモデルが推定した手首の位置で比べ続けます
- お手本と練習を DTW（動的時間伸縮法）で対応づけるので、速さが違っても比べられます
- 「手の位置」「手の形」「表情」「頭の動き」に分けて採点し、いちばんずれた場面と中身を文章で示します（例：「首のかしげが小さめです」）
- お手本と練習を人型で並べて再生し、ずれの大きい場面を色の帯で示します
- 単語と見本を「単語帳」として書き出し、ほかの人と共有できます。手と体の座標の JSON なので、あとで認識モデルの学習データにも使えます

## 動かし方

Node.js 22.12 以降が必要です。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` をブラウザで開きます。
初回は `npm run setup` が自動で走り、MediaPipe のモデル（約17MB）を `public/mediapipe/` に取り込みます。

カメラは `localhost` か HTTPS でないと使えません。
アプリに組み込まれたブラウザなど、カメラを許可しない環境では動画ファイルを使ってください。

## 使い方

### 手話者：語彙を登録する（記録モード）

1. 右の欄に単語を追加します（例：ありがとう）。「基本の単語と言い回しを追加」を押すと、あいさつ・返事・質問・家族・時・数などの基本語と、「よろしくお願いします」のようなよく使う言い回し、あわせて113個が分類ごとに入ります
2. 「カメラを使う」を押し、上半身と両手が映る位置に座ります
3. 「見本を撮る」で手話を記録します。手を下ろした状態から始めて、終わったら手を下ろします
4. 同じ単語の見本を何回か撮ると、読み取りが安定します。最初の見本がお手本になります

見本のない単語は一覧に点線で表示されます。見本を撮ると、見本のない次の単語へ自動で進むので（設定で切れます）、スペースキーで撮る→次の単語、を繰り返して語彙をまとめて登録できます。

1語ずつの動画がすでにあるときは「動画をまとめて見本にする」で複数のファイルを選ぶと、ファイル名を単語名として読んで、まとめて見本にします。
「おはよう.mp4」「おはよう_2.mp4」のように番号を付ければ、同じ単語の見本を何本でも入れられます。一覧にない名前の単語は新しく追加します。

基本の単語帳に入っているのは単語の名前だけで、手話の動きは入っていません。
日本手話の動きを自由に使える公開データがまだなく、動きを作って入れると間違った手話を覚えさせてしまうためです。
日本手話特有の慣用表現も、ろう者の監修のもとで追加してください。

手話の動画ファイルも読み込めます。お手本がまだない単語では見本（お手本）として、ある単語では練習として保存します。
記録の一覧の「見本にする」「お手本にする」で、あとから種類を変えられます。

### 見本の動きをどこから手に入れるか

2026年10月時点で調べた範囲では、日本手話の動きを公開アプリに同梱してよい形で配っているところは見つかりませんでした。

| 入手先 | 中身 | 使える条件 |
| --- | --- | --- |
| NHK（手話CG） | モーションキャプチャーした約7,000語 | 一般向けの公開や利用条件は見当たりません。使うには NHK の許諾が必要です |
| 工学院大学 KoSign（国立情報学研究所 IDR から提供） | 約6,300語の3次元動作と映像 | 研究機関が同意書を出して利用します。公開アプリでの再配布ができるかは利用規約の確認が必要です |
| JSL-DC | 270語、3.6万本の動画 | CC BY 4.0 で公開予定と書かれていますが、まだ公開されていません |
| 自治体の手話動画（例：福岡県） | 数十語程度 | 著作権は自治体にあり、再利用には問い合わせが必要です |

いちばん確実なのは、ろう者や手話通訳者に1語1ファイルで撮ってもらい、「動画をまとめて見本にする」で取り込むことです。
許諾を得た動画集も、同じ方法で単語帳にできます。

### 字幕にする（読み取りモード）

上の「読み取りモード」に切り替え、カメラの前で1語ずつ手話をします。
手を止めるか下ろすと、その区切りを登録済みの全単語の見本と比べ、一番近い単語を画面下の字幕に出します。
いちばん近くても50点に届かないときは「？」になります。読み取った単語は、点数とほかの候補つきで「字幕」の欄に残ります。

「動画に字幕を付ける」を押すと、動画ファイルの手話を順に読み取り、動画内の時刻つきで並べます。

### 話しながら覚える（話して練習）

上の「話して練習」に切り替えて「話す」を押し、話しかけます（文を入力しても同じです）。
話した文が字幕になり、単語帳にある言葉が太字になって、その見本が人型の手話モーションで順に再生されます。
「食べます」は「食べる」、「三」は「3」のように、言い方が少し違っても単語帳の言葉に結びつけます。
字幕の太字の言葉を押すとそこから再生し、「ゆっくり」で半分の速さになります。点線の言葉は単語帳にありますが、まだ見本がありません。

「カメラも使う」を押すと、手話モーションが自分の映像の左上に小さく出るので、見ながら一緒に手話できます。

音声認識はブラウザの機能（Web Speech API）を使うので、Chrome か Safari が必要です。
Chrome では音声が Google のサーバーに送られて文字になります。音声を外に出したくないときは、文を入力してください。

### 練習者：お手本と比べる（記録モード）

1. 手話者の単語帳を「単語帳を読み込む」で取り込むか、自分で見本を登録します
2. 単語を選んで「練習する」（またはスペースキー）を押すと、記録してすぐに点数が出ます
3. 「並べて再生」で、お手本（薄い線）と自分の動きを重ねて見比べます

読み取りモードで自分の手話が正しく字幕になるかを試すのも練習になります。
練習の記録は採点にだけ使い、読み取りの比較相手には入れません。

### 単語帳を共有する

「単語帳を書き出す」で、単語と見本を1つの JSON ファイルに保存します。
「練習の記録も含める」「動画も含める」で中身を選べます。動画を含めるとお手本の映像も見られますが、ファイルは大きくなります。
読み込むと今ある単語帳に追加され、同じ名前の単語は1つにまとまります。

## 採点のしくみ

| 項目 | 比べるもの | 単位 |
| --- | --- | --- |
| 手の位置 | 肩の中心から見た手首の位置 | 肩幅 |
| 手の形 | 手首から見た21関節の位置 | 手の長さ（手首〜中指の付け根） |
| 表情 | 眉・目・口の動き17種 | 0〜1 |
| 頭の動き | 首振り・うなずき・かしげの角度。手話を始める前の構えからの変化で比べます | 度 |

体の大きさやカメラとの距離が違っても比べられるよう、どの値も肩や手の大きさで割ってから比べます。
フレームごとのずれを DTW で最小になるように対応づけ、その平均を点数に換算しています。

点数の換算基準は [`src/scoring.ts`](src/scoring.ts) の `HALF_SCORE`（50点になるずれの大きさ）です。
これは仮の値なので、同じ手話を何回か撮り、「計算の詳細」に出る値を見ながら調整してください。

「利き手が逆の人として比べる」をオンにすると、左右を入れ替えて比べます。

カメラ枠の右上にある「映像」「ボーン」で、カメラ映像と骨格線の表示をそれぞれ切り替えられます。右下には1秒あたりに処理できたフレーム数（fps）が出ます。

## 単語帳の形式

「単語帳を書き出す」で、次の形の JSON を保存します。

```jsonc
{
  "format": "shuwa-practice",
  "version": 2,
  "words": [{ "id": "…", "label": "ありがとう", "referenceId": "…" }],
  "clips": [
    {
      "id": "…",
      "wordId": "…",
      "kind": "sample",
      "signer": "撮影者の名前（任意）",
      "width": 1280,
      "height": 720,
      "durationMs": 2300,
      "frames": [
        {
          "t": 0,
          "pose": [/* 姿勢23点（頭・肩・肘・手首と手のおおまかな点）× [x, y, z, visibility] */],
          "left": [/* 左手21点 × [x, y, z]（画像上の位置） */],
          "right": [/* 右手 */],
          "leftWorld": [/* 左手21点 × [x, y, z]（メートル） */],
          "rightWorld": [/* 右手 */],
          "face": [/* 表情17種のスコア */],
          "head": [/* [首振り, うなずき, かしげ]（度） */]
        }
      ]
    }
  ],
  // 「動画も含める」のときだけ
  "videos": [{ "clipId": "…", "dataUrl": "data:video/webm;base64,…" }]
}
```

`kind` は `sample`（見本）か `practice`（練習）です。
`left` / `right` は手話をする人から見た左右です。手や顔が映っていないフレームは `null` になります。
version 1 のファイル（`kind` と `videos` なし）も読み込めます。古い記録には `head` がなく、`pose` は17点です。

## 開発

```bash
npm test          # 採点・読み取り・文の照合のテスト
npm run typecheck # 型チェック
npm run build     # 本番用ビルド（dist/）
```

main にプッシュすると、GitHub Actions（[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)）がテストとビルドを行い、GitHub Pages に公開します。
Pages ではサイトが `/<リポジトリ名>/` の下に置かれるため、ビルド時に `BASE_PATH` でその場所を渡しています。

| ファイル | 役割 |
| --- | --- |
| `src/tracker.ts` | MediaPipe で手・姿勢・表情・頭の向きを読み取る |
| `src/recorder.ts` | フレームと動画の記録、前後の切り落とし |
| `src/features.ts` | 体の大きさをそろえた特徴量への変換 |
| `src/dtw.ts` | 動的時間伸縮法 |
| `src/scoring.ts` | 採点とずれた場面の特定 |
| `src/reader.ts` | 手話の区切りの検出と、見本との照合による単語の判定 |
| `src/sentence.ts` | 文の中から単語帳の言葉を探す（活用・数字の言い換えつき） |
| `src/speech.ts` | ブラウザの音声認識 |
| `src/player.ts` | 見本を手話モーションとして順に再生する |
| `src/vocabulary.ts` | 基本の単語と言い回しの一覧 |
| `src/batch.ts` | 動画のファイル名から単語名を読む |
| `src/download.ts` | 進み具合つきのファイル取得 |
| `src/draw.ts` | カメラ映像への重ね描きと人型の描画 |
| `src/storage.ts` | IndexedDB への保存と単語帳の書き出し・読み込み |
| `src/main.ts` | 画面の組み立てと操作 |
