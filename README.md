# 手話れんしゅう帳

手話をカメラで記録し、お手本との動きの違いを点数とタイムラインで確かめる練習ツールです。
ブラウザの中だけで動き、映像や記録はどこにも送信しません。

- MediaPipe で手（両手21点ずつ）・上半身・表情を読み取ります
- お手本と練習を DTW（動的時間伸縮法）で対応づけるので、速さが違っても比べられます
- 「手の位置」「手の形」「表情」に分けて採点し、いちばんずれた場面と手を文章で示します
- お手本と練習を人型で並べて再生し、ずれの大きい場面を色の帯で示します
- 記録は手と体の座標の JSON として書き出せるので、あとで認識モデルの学習データに使えます

## 動かし方

Node.js 22.12 以降が必要です。

```bash
npm install
npm run dev
```

表示された `http://localhost:5173` をブラウザで開きます。
初回は `npm run setup` が自動で走り、MediaPipe のモデル（約17MB）を `public/mediapipe/` に取り込みます。

カメラは `localhost` か HTTPS でないと使えません。
アプリに組み込まれたブラウザなど、カメラを許可しない環境では「動画ファイルから読み込む」を使ってください。

## 使い方

1. 右の欄に単語を追加します（例：ありがとう）
2. 「カメラを使う」を押し、上半身と両手が映る位置に座ります
3. 「お手本を撮る」で手本を記録します。手を下ろした状態から始めて、終わったら手を下ろします
4. 「練習する」（またはスペースキー）で練習を記録すると、すぐに点数が出ます
5. 「並べて再生」で、お手本（薄い線）と自分の動きを重ねて見比べます

手話の動画ファイルも読み込めます。お手本がまだない単語ではお手本として、ある単語では練習として保存します。
記録の一覧の「お手本にする」で、いつでもお手本を差し替えられます。

## 採点のしくみ

| 項目 | 比べるもの | 単位 |
| --- | --- | --- |
| 手の位置 | 肩の中心から見た手首の位置 | 肩幅 |
| 手の形 | 手首から見た21関節の位置 | 手の長さ（手首〜中指の付け根） |
| 表情 | 眉・目・口の動き17種と、頭のうなずき・首振り | 0〜1 |

体の大きさやカメラとの距離が違っても比べられるよう、どの値も肩や手の大きさで割ってから比べます。
フレームごとのずれを DTW で最小になるように対応づけ、その平均を点数に換算しています。

点数の換算基準は [`src/scoring.ts`](src/scoring.ts) の `HALF_SCORE`（50点になるずれの大きさ）です。
これは仮の値なので、同じ手話を何回か撮り、「計算の詳細」に出る値を見ながら調整してください。

「利き手が逆の人として比べる」をオンにすると、左右を入れ替えて比べます。

## 書き出しデータの形式

「記録を書き出す」で、次の形の JSON を保存します（動画は含みません）。

```jsonc
{
  "format": "shuwa-practice",
  "version": 1,
  "words": [{ "id": "…", "label": "ありがとう", "referenceId": "…" }],
  "clips": [
    {
      "id": "…",
      "wordId": "…",
      "signer": "撮影者の名前（任意）",
      "width": 1280,
      "height": 720,
      "durationMs": 2300,
      "frames": [
        {
          "t": 0,
          "pose": [/* 姿勢17点 × [x, y, z, visibility] */],
          "left": [/* 左手21点 × [x, y, z]（画像上の位置） */],
          "right": [/* 右手 */],
          "leftWorld": [/* 左手21点 × [x, y, z]（メートル） */],
          "rightWorld": [/* 右手 */],
          "face": [/* 表情17種のスコア */]
        }
      ]
    }
  ]
}
```

`left` / `right` は手話をする人から見た左右です。手が映っていないフレームは `null` になります。

## 開発

```bash
npm test          # 採点ロジックのテスト
npm run typecheck # 型チェック
npm run build     # 本番用ビルド（dist/）
```

| ファイル | 役割 |
| --- | --- |
| `src/tracker.ts` | MediaPipe で手・姿勢・表情を読み取る |
| `src/recorder.ts` | フレームと動画の記録、前後の切り落とし |
| `src/features.ts` | 体の大きさをそろえた特徴量への変換 |
| `src/dtw.ts` | 動的時間伸縮法 |
| `src/scoring.ts` | 採点とずれた場面の特定 |
| `src/draw.ts` | カメラ映像への重ね描きと人型の描画 |
| `src/storage.ts` | IndexedDB への保存と JSON の書き出し |
| `src/main.ts` | 画面の組み立てと操作 |
